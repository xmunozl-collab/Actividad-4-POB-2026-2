## Descripción

Este repositorio contiene la solución en Python (con la librería tkinter) de los ejercicios 6.4 a 6.8
del libro *Ejercicios de programación orientada a objetos con Java y UML* de Leonardo Bermón Angarita,
solicitados en la Actividad 4. Todos los ejercicios se resuelven mediante interfaz gráfica de usuario.
